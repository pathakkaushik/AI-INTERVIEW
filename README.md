# AI MockPrep - Full-Stack AI Interview Platform

This repository is structured into two main packages: **`frontend`** and **`server`**.

## 📁 Directory Layout

- `frontend/`: React + Vite web application
- `server/`: Node.js + Express API server with MongoDB & AI Services

## 🚀 Running Locally

### 1. Run Frontend
```bash
cd frontend
npm run dev
```
Local URL: `http://localhost:5173/`

### 2. Run Backend Server
```bash
cd server
node server.js
```
Backend API: `http://localhost:5000/`
